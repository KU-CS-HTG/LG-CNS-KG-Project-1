# 챗봇 대조 실험 — "그냥 ChatGPT에 물어보기"와 무엇이 다른가 (2026-09-17, 발표 5장 근거)

> 목적: 설명서 1장 "왜 그냥 ChatGPT에 물어보기와 다른가" 표를 **주장이 아니라 실제 챗봇 출력**으로 뒷받침한다.
> 상태: **3개 챗봇 완료** — ChatGPT(정재우, A×2·B·C) · 뤼튼(팀원, A + 출처 추궁) · Gemini(팀원, A + 과목명 요구). 3절 판정표가 최종본.
> 결론 한 줄: **챗봇은 비우거나(ChatGPT) 출처 없이 단정한다(뤼튼·Gemini). 둘 다 검증할 수 없다.** ChatGPT가 "못 한다"고 스스로 열거한 네 가지(전수 순위·실제 과목명·요구 역량 개수·출처 URL)가 우리 카드의 네 줄이고, 뤼튼이 채운 과목 3개 중 2개·Gemini가 "공식 개설 과목명"이라며 채운 8개 중 4개는 서울대 3,829개 과목에 없다.

## 1. 프로토콜 (팀원용 — 이대로 해야 열을 나란히 놓을 수 있다)

### 설정 3가지
| 항목 | 방법 | 증거로 남길 것 |
|---|---|---|
| 새 대화 | 임시 채팅 / 시크릿 창 / 메모리·맞춤화 끔 | 화면에 "임시 채팅" 등 표시 |
| 웹 검색 끔 | 끄는 스위치는 보통 없다. **프롬프트 첫 줄에 명시**: `웹 검색을 사용하지 말고, 네가 이미 알고 있는 것만으로 답해 줘.` | 답 끝에 `[1] https://…` 링크 목록이 **없으면** 검색 안 한 것. 있으면 검색한 것 |
| 모델·날짜 | 화면의 모델 표시(ChatGPT는 입력창 우측 `5.6 중간`)가 보이게 스크린샷 | 스크린샷 + 답변 전문 복사 |

검색 켬 버전도 하나 찍어 두면 좋다 — "검색해도 안 되는 것"을 보일 수 있다.

### 프롬프트 (글자 그대로 — 우리 인터뷰 모드 세트 4 자기소개와 동일)

**A — 고등학생이 실제로 칠 법한 말**
```
웹 검색을 사용하지 말고, 네가 이미 알고 있는 것만으로 답해 줘.
안녕하세요. 저는 고등학생이고 진로를 고민 중이에요.
수학이랑 통계를 좋아하고, 친구들이랑 데이터로 뭔가 분석해서 발표하는 게 재밌어요. 숫자 보면 패턴 찾는 걸 잘한다고 친구들이 말해요.
통계 수업에서 배운 걸로 학교 설문 데이터를 파이썬으로 분석해 봤어요.
동아리에서 발표 자료 만들고 정리하는 걸 자주 맡아요.
저한테 맞는 대학 전공이랑, 나중에 갈 수 있는 LG 계열사 신입 직무를 추천해 주세요.
```

**B — 같은 창에서 이어서, 우리 카드와 같은 형식을 요구 (핵심)**
```
웹 검색은 계속 사용하지 말고, 아래 형식으로 답해 주세요.
1. 서울대학교 전체 전공 중에서 순위를 매겨, 1위 전공과 "몇 개 전공 중 1위"인지
2. 그 전공에서 위 역량을 기르는 실제 개설 과목명 3개
3. LG 계열사 신입 채용공고 중 맞는 직무 1개 — 공고가 요구하는 역량 개수, 그중 내가 이미 갖춘 개수, 아직 없는 역량
4. 과목명과 공고의 출처 URL
```

**C — 새 임시 채팅에서, 같은 뜻 다른 말 (재현성)**
```
웹 검색을 사용하지 말고, 네가 이미 알고 있는 것만으로 답해 줘.
고2인데요, 통계랑 수학 과목이 제일 좋고 설문 결과를 파이썬으로 정리해서 발표한 적 있어요. 규칙 찾는 거에 소질 있다는 말 들어요. 발표 자료 만드는 것도 자주 해요.
어울리는 전공이랑 LG 신입 직무 알려주세요.
```

**D — 역방향 (시간 되면, 세트 5 대조)**
```
LG CNS Smart Factory 신입 직무에 가려면 서울대 어느 전공이 유리한가요? 그 전공에서 관련 과목 3개도 알려주세요.
```

**E — 출처 추궁 (챗봇이 과목명·직무명을 채워 넣었을 때, 같은 창에서 이어서. 뤼튼 실험에서 팀원이 추가 — 효과 좋음)**
```
방금 말한 전공 과목이랑 LG 직무 정보는 어디서 가져온 거야?
```

### 판정법
- **과목명 실재**: 챗봇이 말한 과목명을 `data/subject_cleaned.csv`(서울대 3,829개 과목)에서 찾는다. `grep "회귀분석" data/subject_cleaned.csv`
- **URL**: 클릭해서 열리는지, 특정 공고(`careers.lg.com/apply/detail?id=…`)인지 일반 페이지인지
- **재현성**: A와 C의 1위 전공이 같은지, 목록 구성·개수가 같은지
- **커버리지**: "요구 N개 중 M개"를 말했는지, 말했다면 N이 실제 공고에서 왔는지

### E (출처 추궁) → 자백
> "내가 말한 전공 과목 정보는 **실제 특정 출처에서 가져온 게 아니라**, 보통 대학교의 … 학과에서 공통적으로 개설하는 과목들을 기반으로 알려준 거야."

## 2-C. Gemini 결과 (팀원 · 임시 채팅 · 2026-09-17)

## 4. 발표 5장에 쓸 것

### 핵심 문장 (설명서 1장 표 문구 수정 제안)
현재 표의 "지어낸 과목명에는 붙일 출처가 없다"는 절반만 맞다 — ChatGPT는 지어내지 않고 **비웠고**, 뤼튼은 **채웠는데 우리 데이터에 없다**. 둘을 모두 담는 문장:

> 같은 질문에 ChatGPT는 "검증할 수 없다"며 비웠고, 뤼튼은 그럴듯한 과목명과 직무명으로 채웠다 — 3,829개 과목에 없는 이름으로.
> 고등학생은 이 둘을 구분할 수 없다. 우리는 3,829개 과목·172개 직무를 데이터로 갖고 있어 "안다"고 말할 수 있고, 매 실행 확인 3건으로 증명한다.

### 슬라이드 인용문 (원문 그대로)
1. ChatGPT: "'전체 N개 중 1위', '실제 개설 과목 3개', '실제 채용공고의 요구 역량 N개', '출처 URL'은 모두 외부 원문 확인이 필요한 항목이라 웹 검색 없이 정확성을 보장할 수 없습니다." — 우리 카드 네 줄과 1:1
2. 뤼튼: "LG CNS 데이터 분석 직무를 추천해! … 실제로 이 직무에서 요구하는 주요 역량은 통계 이해, 코딩(Python 등), 대용량 데이터 처리, 그리고 의사소통 능력이야." → 옆에 우리 스냅샷의 CNS 신입 직무 9개 목록 (데이터 분석 없음)
3. 뤼튼 (추궁 후): "내가 말한 전공 과목 정보는 실제 특정 출처에서 가져온 게 아니라" — 물어봐야 나오는 자백
4. ChatGPT: "각 학교의 통계학과·데이터사이언스학과·산업공학과 1~4학년 교육과정을 나란히 놓고 비교해 보세요" / 뤼튼: "대학 공식 홈페이지 가면 학과별 과목 소개가 … 참고하면 더 정확하고" — **두 챗봇 다 학생더러 직접 하라고 한 일**이 우리 프로젝트가 하는 일

### 한 장 구성 제안 (5장)
왼쪽 뤼튼 과목 3개 ↔ grep 결과(✗ ✗ 수학교육과) / 가운데 ChatGPT "보장할 수 없습니다" / 오른쪽 우리 카드 `✓ Data Analysis (과목 7개)` + `출처 · 대학알리미`. 한 줄 캡션: "채우거나 비우거나 — 근거 데이터가 있어야 구분된다."

### 작은 차별점 — 과목 선정 기준
ChatGPT의 3개(회귀분석·수리통계·다변량)는 **통계학과의 대표 과목**. 우리 카드의 3개(기계학습과 계산금융·데이터마이닝·다변량자료분석)는 **직무가 요구하고 전공도 기르는 역량의 다리 과목**. 같은 전공에서 뽑아도 기준이 다르다.

### 챗봇이 잘한 것도 말한다
"패턴을 찾고 → 코드로 분석하고 → 설명하는 쪽에 강점" 같은 **해석과 문장**은 ChatGPT가 잘 쓴다. 이게 설계서 아이디어 ④의 **표현(explain)** 역할이고 우리도 그 부분은 LLM에 맡긴다. 결과는 "챗봇 vs 우리"가 아니라 "표현은 LLM, 판정은 그래프"라는 역할 분담이 맞았다는 증거다.
