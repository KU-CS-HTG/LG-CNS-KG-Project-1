# 쉽게 읽는 프로젝트 소개 — "내 관심사로 전공과 첫 직장을 이어 주는 지도"

> 이 프로젝트를 처음 보는 분을 위한 글입니다. 코드나 AI 용어를 몰라도 끝까지 읽을 수 있게 썼습니다.
> 더 깊이 알고 싶으면 [프로젝트-설명서.md](프로젝트-설명서.md)(기술 문서)로 가시면 됩니다. 기준: 2026-09-17, 발표 하루 전.

---

## 1. 한 문장으로

**고등학생이 "나는 이런 걸 좋아하고 이런 걸 잘해요"라고 말하면, "그럼 이 전공에 가서 이 과목을 듣고, 나중에 LG의 이 일을 할 수 있어요"라고 근거와 함께 답해 주는 프로그램**입니다.

---

## 2. 왜 만들었나

진로 고민을 챗봇에게 물어보면 그럴듯한 답이 나옵니다. 그런데 세 가지가 빠져 있습니다.

| 챗봇의 답 | 빠진 것 |
|---|---|
| "통계학과가 잘 맞을 것 같아요" | **어떤 전공들과 비교했는지** — 떠오른 서너 개 중에 고른 것 |
| "데이터 분석 과목을 들으세요" | **그 과목이 실제로 있는지** — 지어낸 과목명일 수 있음 |
| "데이터 분석가로 일할 수 있어요" | **그 회사가 실제로 무엇을 요구하는지** — 채용 공고를 본 적이 없음 |

우리는 이 세 가지를 **데이터로** 채웠습니다. 실제 대학 교육과정, 실제 채용 공고를 모아서 "전공 – 역량 – 직무"를 선으로 이은 **지도**를 만들고, 답을 그 지도 위에서만 찾습니다.

## 4. 어떻게 동작하나 — 지도 만들기와 지도 읽기

프로그램은 두 단계로 나뉩니다. **지도를 미리 만들어 두는 단계**(한 번만)와 **학생이 올 때마다 지도를 읽는 단계**입니다.

### 4-1. 지도 만들기 (미리, 한 번만)

```
과목 이름 3,829개  ──AI가 읽음──▶  "이 전공은 이런 역량을 기른다"      예) 통계학과 → 데이터 분석, 통계
채용 공고 172개    ──AI가 읽음──▶  "이 직무는 이런 역량을 요구한다"    예) 소재개발AX → 데이터 분석, 머신러닝
                                          │
                              같은 말은 같은 이름으로 통일 (사전 139개 단어)
                                          │
                                          ▼
                     지도 완성:  전공 61개 ─ 역량 120개 ─ 직무 108개
```

여기서 AI(LLM)가 하는 일은 딱 하나, **글에서 역량 이름을 뽑아내는 것**입니다. 그리고 뽑은 결과는 파일에 저장해 두므로(캐시), 같은 글을 다시 읽히지 않습니다. 이 단계에 AI를 부른 횟수는 전부 합쳐 277번이고, 그 뒤로는 0번입니다.

**사전(통제 어휘)이 왜 필요한가** — 과목은 "데이터마이닝", 공고는 "빅데이터 분석", 학생은 "데이터 분석이 재밌어요"라고 말합니다. 전부 같은 뜻인데 글자가 다르면 선이 안 이어집니다. 그래서 팀이 관리하는 사전을 두고, **사전에 있는 단어로만** 지도를 그립니다. 사전에 없는 말은 버리지 않고 "추가 후보" 목록에 모아 뒀다가 사람이 검토합니다.

**"~의 한 종류다" 관계(IS_A)** — 공고는 "Oracle(오라클)을 다룰 줄 아는 사람"을 찾고, 대학은 "데이터베이스" 과목을 엽니다. 이 둘을 잇기 위해 사전에 "Oracle은 Database의 한 종류"라고 적어 둡니다. 사과가 과일의 한 종류인 것과 같습니다. 이 관계가 102개 있고, 덕분에 도구 이름(Java, AWS, CATIA…)을 요구하는 직무가 학문 이름(프로그래밍, 클라우드, 기계설계)을 기르는 전공과 이어집니다.

### 4-2. 지도 읽기 (학생이 올 때마다)

```
① 학생 이야기  →  역량 태그         "데이터 분석이 재미있어요, 통계 수업 들었어요"  →  [데이터 분석, 통계]
② 태그  →  전공 순위                전공 61개를 전부 비교해서 1위를 고름                →  통계학과
③ 전공  →  직무                     그 전공이 기르는 역량 전체로 직무를 찾음            →  LG에너지솔루션 소재개발AX
④ 전공·직무  →  과목                 둘을 잇는 역량을 기르는 과목 3개                    →  데이터마이닝 방법 및 실습 …
⑤ 카드 + 설명 문단                  ①~④를 카드로 보여 주고, AI가 친절한 말로 풀어 씀
```

**중요한 원칙: 판정은 AI가 하지 않습니다.** ②③④는 사전 찾기와 집합 계산(겹치는 것 세기)으로만 합니다. 그래서 같은 이야기를 두 번 넣으면 같은 답이 나오고, 카드에 적힌 과목·직무는 전부 지도에 실제로 있는 것입니다. AI는 ①(이야기에서 태그 뽑기)과 ⑤(문단 쓰기)만 맡습니다. 학생 한 명당 AI 호출은 2번(질문 3개 방식)이고, 대화 방식은 20번 안팎입니다.

## 5. 학생에게 보이는 화면

실제 출력입니다. 입력은 "데이터 분석이 재미있어요 / 통계 수업, 파이썬으로 데이터 정리".

```
[프로필]  Data Analysis · Statistics · Python

[전공]    통계학과
          61개 전공 중 역량이 이어지는 46개를 비교한 결과 1위
          ✓ Data Analysis (과목 7개) · Statistics (과목 14개)      ← 내 역량이 어느 과목으로 이어졌나
          ○ 아직 안 이어진 역량 — Python                            ← 안 이어진 것도 숨기지 않음
          역량 연결도
            통계학과        █████░░░░░ 46%
            화학생물공학부  ████░░░░░░ 39%
            첨단융합학부    ████░░░░░░ 38%

[과목]    통계학과에서 이 역량을 기르는 과목
          기계학습과 계산금융 → Machine Learning
          데이터마이닝 방법 및 실습 → Data Analysis
          다변량자료분석 및 실습 → Data Analysis

[직무]    LG에너지솔루션 소재개발AX (신입)
          요구 역량 2개 중 2개 커버
          ✓ Data Analysis, Machine Learning
          공고 → https://careers.lg.com/apply/detail?id=1002075     ← 실제 공고 링크

[다음 후보]
          LG CNS AI (AX) (신입) — 요구 10개 중 7개 커버 (정확 1 · 계열 6)
          ...
──────────
출처 · 과목: 서울대학교 교육과정 — 대학알리미 · 공고: LG Careers
```

그 아래에 AI가 쓴 **[진로 추천] 문단**이 붙습니다. "61개 전공을 모두 살펴봤고, 당신의 역량과 이어지는 46개 중에서 통계학과가 가장 잘 이어졌어요. …" 처럼 카드의 내용을 풀어서 설명하되, 카드에 없는 과목이나 회사 이야기는 지어내지 않도록 규칙을 뒀습니다.

읽는 법 세 가지:
- **"46%"는 "46% 어울린다"가 아닙니다.** 학생의 역량이 그 전공 과목과 얼마나 이어지는지를 나타내는 점수입니다. 그래서 이름을 "역량 연결도"라고 붙였습니다.
- **✓ / ≈ / ○** — ✓ 정확히 같은 역량, ≈ "~의 한 종류"로 이어진 역량, ○ 아직 안 이어진 역량.
- **직무는 학생의 태그가 아니라 "1위 전공이 기르는 역량 전체"로 찾습니다.** "이 전공을 거쳐 갈 수 있는 직무"가 서비스의 뜻이기 때문입니다.

## 6. 학생의 이야기를 받는 방법 4가지

| 방법 | 어떻게 | 언제 쓰나 |
|---|---|---|
| 대화 (기본) | 자기소개 한 문단 → AI가 부족한 부분을 그때그때 물어봄 (관심사·공부 스타일·강점·생활·친구·가치관) | 웹 화면. 가장 자연스럽지만 질문이 길어질 수 있음 |
| 짧은 인터뷰 | 자기소개 → 관심사·강점이 부족할 때만 정해진 질문 1~2개 | 시연용. 빠르고 결과가 안정적 |
| 저장된 프로필 | 전에 만든 프로필 파일을 읽어서 바로 추천 | 대화 없이 결과만 볼 때 |
| 질문 3개 | 관심 분야 / 해 본 것 / 데이터·시스템·사람 중 끌리는 쪽 | 처음 만든 방식. 가장 단순 |

네 방법 모두 결국 같은 모양의 입력(역량 태그 + 성향)으로 바뀌어 4-2의 지도 읽기로 들어갑니다.

**성향은 어떻게 쓰나** — 대화에서 "친구들이 역할 나누는 걸 저한테 맡겨요" 같은 말이 나오면 '조정능력'이라는 성향으로 기록됩니다. 성향은 두 곳에 조심스럽게 씁니다. 하나는 역량 추정("수리적 사고가 강하면 통계를 시사한다" — 절반만 믿음), 다른 하나는 직무의 요구 태도("협업·문제해결")와 맞춰 보기(점수엔 안 넣고 동점일 때만). **약점은 묻지도, 쓰지도 않습니다.** "어려워하는 게 있다"는 이유로 어떤 직무가 안 맞는다고 말하지 않기로 했습니다.

## 7. 챗봇과 무엇이 다른가 — 우리 화면에만 있는 문장

| 우리 카드에 있는 것 | 챗봇이 못 하는 이유 |
|---|---|
| "61개 전공 중 … 46개를 비교한 결과 1위" | 전체를 놓고 비교한 적이 없음 |
| "✓ Data Analysis (과목 7개)" / "○ Python" | 무엇이 이어지고 무엇이 안 이어지는지 세어 본 적이 없음 |
| "요구 역량 10개 중 7개 커버 (정확 1 · 계열 6)" | 공고를 읽은 적이 없고, 도구 이름과 학문 이름이 같은 뜻이라는 관계를 모름 |
| 과목명·직무명이 전부 실제 데이터에 있음 + 공고 링크 | 지어낸 이름에는 붙일 출처가 없음 |
| 같은 이야기 → 같은 답 | 판정을 AI가 하면 매번 조금씩 달라짐 |

## 8. 제대로 되는지 어떻게 확인하나

- **정답지 24개**: "이런 입력이면 이 전공이 3위 안에, 이런 직무가 나와야 한다"를 미리 적어 둔 시험 문제입니다. IT 10개, 배터리·재료·전력·통신·마케팅·회계·디자인·로봇·공정 등 비IT 10개, 대화 방식 4개. 무언가를 고칠 때마다 이 24개를 자동으로 돌려 전부 통과하는지 봅니다 (지금 24/24).
- **확인 3가지**: ① 같은 뜻의 다른 문장 두 개가 같은 전공을 내는가 ② 화면의 과목·직무·회사 이름이 전부 데이터에 있는가 ③ "커버 + 부족 = 요구 전체"가 맞는가.
- 고칠 때 눈으로 서너 개 보고 결정하지 않고, 이 정답지로 결정합니다. 실제로 이 정답지 덕분에 "새 단어를 사전에 넣었더니 엉뚱한 직무가 1위로 올라오는" 문제를 두 번 잡았습니다.

## 11. 용어 다섯 개만

| 용어 | 쉬운 말 |
|---|---|
| 지식그래프 (knowledge graph) | 사물(전공·역량·직무)을 점으로, 관계("기른다", "요구한다")를 선으로 그린 지도 |
| 통제 어휘 (controlled vocabulary) | 지도에 쓸 수 있는 단어를 정해 둔 사전. 같은 뜻은 한 단어로 |
| IS_A | "~의 한 종류다". Oracle은 Database의 한 종류, Java는 프로그래밍의 한 종류 |
| LLM | 글을 읽고 쓰는 AI. 여기서는 역량 뽑기와 문단 쓰기만 |
| 평가셋 (eval set) | 미리 적어 둔 정답지. 고칠 때마다 자동으로 채점 |
