| 케이스 | rep | 강점 성향(raw) | A 1.0 | B 0.5 | C 제외 |
|---|---|---|---|---|---|
| I2 | 1 | 조정능력·문제해결 | ✓ 컴공 | ✗ 건설환경 | ✓ 컴공 |
| I2 | 2 | 조정능력·문제해결 (동일) | ✗ 건설환경 | ✗ | ✗ |

→ 흔들리는 곳은 두 LLM 호출: ① 강점 분석(I4: 같은 입력에 다른 성향) ② 태거(I2: 같은 텍스트에 Software Engineering 이 붙었다 안 붙었다). 가중치로는 못 잡는다.

### 정정 (저녁) — "규칙이 지워졌다" 는 틀렸다
33b0480 의 prompts.py −101줄은 **중복 정의돼 있던 `AREA_ANALYSIS_PROMPT`(앞쪽, 실행 시엔 뒤쪽 정의에 가려져 있던 것)를 지운 것**이다.
실행 시점의 프롬프트 텍스트를 두 버전에서 뽑아 비교하면 차이는 **약점 관련 줄만**이다: 영역 7→6, `direction: strength / weakness / neutral` → `strength / neutral`, "약점을 학과·직무 부적합으로 판단하지 마세요" 삭제.
같은 커밋의 `vocabulary.py` MAPPING_RULES 8번도 바뀌었다: `strength: 강점으로 나타남` → **`강점으로 명확하게 나타남`**, `neutral: 단순한 성향` → `일반적인 성향`, weakness 설명 삭제, 14번(약점→부적합 금지) 삭제.

## 실험 3 — 어디를 되돌려야 안정되나 (임시 수정 → 실행 → 원복)

| 변형 | 바꾼 것 | I2 ×2 | I4 ×2 | 강점 추출 |
|---|---|---|---|---|
| 현재(main) | — | ✓/✗ 흔들림 | ✓/✗ 흔들림 | 발표력·설득력 ↔ 분석성만 |
| **rules** | `vocabulary.py` MAPPING_RULES 8번 원문 복원만 ("명확하게" 제거, weakness 설명 복원) | ✓ ✓ | ✓ ✓ | strength 0.7~0.9 로 2~3개 |
| **all** | rules + direction 라벨 3개 복원 (`schemas.py` Literal, `prompts.py` 3곳, 부적합 금지 문장) | ✓ ✓ | ✓ ✓ | 발표력·창의성·설득력 — 두 번 동일 |

해석: 엄격해진 곳은 **분류 라벨의 문구**다. ① "강점으로 **명확하게** 나타남" 이 문턱을 올려 경계 성향(발표력 0.7~0.8)이 neutral 로 떨어지고, ② weakness 라벨이 사라져 이분법(strength/neutral)이 되면서 애매한 성향이 neutral 쪽으로 밀린다. `TRAIT_MIN_CONFIDENCE 0.6` 이상의 strength 만 쓰는 우리 쪽에선 그게 곧 "요구 태도 ✓ 없음" 이다.
## 제안 (정정판)

"prompts.py 롤백 후 weakness 만 찾아서 삭제" 는 **지금 상태로 돌아오는 것**이라 의미가 없다 (실행 시점 차이가 곧 weakness 줄들이므로).
**영역과 라벨을 구분**해야 한다:

- **약점 영역(area)** — 질문·프로필 필드·`PROFILE_AREAS` 항목: **삭제 유지** (팀 결정 "묻지 않는다"). 이미 돼 있음.
- **약점 라벨(direction)** — 분류 선택지로는 **남긴다**: `schemas.py` `Literal["strength","weakness","neutral"]`, `prompts.py` 의 `direction: strength / weakness / neutral` 3곳, "약점을 학과·직무 부적합으로 판단하지 마세요" 문장. 코드는 어디서도 weakness 라벨을 쓰지 않는다 (`interview.py` 는 `direction == "strength"` 만 채택) — 안 쓰는 라벨이 있어야 모델의 strength/neutral 갈림이 예전처럼 나온다.
- **`vocabulary.py` MAPPING_RULES 8번 원문 복원** — 이게 핵심 한 줄: `강점으로 나타남` (← "명확하게" 삭제), `weakness: 부족하거나 부담 요소`, `neutral: 단순한 성향 또는 선호`. 14번("약점은 직무 부적합으로 직접 판단하지 않습니다") 도 복원.
- 검증: `python check.py` **두 번 연속** 4/4.
- 성향 판단 가중치(1.0 vs 0.5) 는 별개 논의 — 이번 회귀와 무관 (실험 1).
