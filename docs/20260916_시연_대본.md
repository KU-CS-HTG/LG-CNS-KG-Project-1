## 세트 1 — 기본: 데이터 분석 → 통계학과 → 소재개발AX (평가셋 #1)

**입력** (3질문 모드)
1. 데이터 분석이 재미있어요
2. 통계 수업, 파이썬으로 데이터 정리
3. 1

```
[프로필]  Data Analysis · Statistics · Python

[전공]    서울대학교 통계학과
          61개 전공 중 IT 역량이 검출된 46개를 비교한 결과 1위
          0.46 통계학과 / 0.39 화학생물공학부 / 0.38 첨단융합학부

[과목]
          기계학습과 계산금융 → Machine Learning  [서울대학교 개설]
          데이터마이닝 방법 및 실습 → Data Analysis  [서울대학교 개설]
          다변량자료분석 및 실습 → Data Analysis  [서울대학교 개설]

[직무]    LG에너지솔루션 소재개발AX (신입)
          요구 역량 2개 중 2개 커버
          ✓ Data Analysis, Machine Learning
          다음 후보: LG CNS AI (AX) (신입) — 요구 10개 중 7개 커버
```

**말할 것**
- "61개 전공 **전수** 비교 1위" — 상위 3개만 주는 챗봇과 다른 점 (설계서 차별화 ①)
- 과목이 **다리**다: 전공(통계학과)과 직무(소재개발AX)가 공유하는 역량의 근거 과목만 골랐다. 과목명이 실제 서울대 교육과정에 있다 (확인 항목 2)
- 직무 "요구 2개 중 2개 커버" — 커버 + 갭 = 요구 전체 (확인 항목 3)
- 다음 후보 AI (AX) 는 요구 10개 중 7개 — 역량이 많은 직무는 코사인에서 불리하다는 한계를 스스로 말해도 좋다

## 세트 2 — 계열 커버: AI 모델 → 컴퓨터공학부 → Smart Factory (평가셋 #3)

**입력**
1. 이미지 인식, AI 모델 만들기
2. 수학이랑 코딩
3. 2

```
[프로필]  Machine Learning · Computer Vision · Programming · Software Engineering

[전공]    서울대학교 컴퓨터공학부
          61개 전공 중 IT 역량이 검출된 15개를 비교한 결과 1위
          0.67 컴퓨터공학부 / 0.31 융합학습과학전공 / 0.26 전기?정보공학부

[과목]
          기계학습 개론 → Machine Learning  [서울대학교 개설]
          인공지능 → Machine Learning  [서울대학교 개설]
          소프트웨어공학 → Software Engineering  [서울대학교 개설]

[직무]    LG CNS Smart Factory (신입)
          요구 역량 6개 중 6개 커버 (정확 1 · 계열 5)
          ✓ Machine Learning
          ≈ Programming 계열로 커버 — C#, Java, Python
          ≈ Machine Learning 계열로 커버 — LLM
          ≈ Software Engineering 계열로 커버 — React
          다음 후보: LG CNS AI (AX) (신입) — 요구 10개 중 8개 커버
```

**말할 것**
- "정확 1 · 계열 5" — **IS_A 온톨로지**가 일하는 장면. 직무는 C#·Java·Python·LLM·React 를 요구하고 전공은 Programming·Machine Learning·Software Engineering 을 기른다. 글자가 같아야 이어지는 flat 어휘면 1개만 겹친다
- 추론은 **위로만** — "Java 는 Programming 의 한 종류" 는 참, "Programming 을 배우면 Java 를 안다" 는 안 말한다 (환각 방지)

## 세트 3 — 비IT 확장: 프로젝트·발표 → 경영학과 → 영업마케팅 (평가셋 #7)

**입력**
1. 사람들이랑 프로젝트 굴리는 게 좋아요
2. 동아리 회장, 발표
3. 3

```
[프로필]  Project Management · Management · Agile

[전공]    서울대학교 경영학과
          61개 전공 중 IT 역량이 검출된 15개를 비교한 결과 1위

[과목]
          비즈니스 애널리틱스 개론 → Data Analysis  [서울대학교 개설]
          경영빅데이터분석개론 → Data Analysis  [서울대학교 개설]
          금융공학과 퀀트분석 → Finance  [서울대학교 개설]

[직무]    LG에너지솔루션 영업마케팅 (신입)
          요구 역량 3개 중 3개 커버
          ✓ Accounting, Data Analysis, Finance
          요구 태도: Communication · Collaboration · Problem Solving
```

- 한계도 말한다: Management 는 넓은 말이라 태거가 과하게 붙일 수 있다 → 평가셋으로 감시

## 세트 4 — 인터뷰 모드: 자기소개 한 번으로 (I1)

**실행** `python app.py --interview` → 자기소개 한 문단 입력 (아래 대본 첫 줄). 충분하면 추가 질문 없이 바로 결과.

**대본**
> ['안녕하세요. 저는 수학이랑 통계를 좋아하고, 친구들이랑 데이터로 뭔가 분석해서 발표하는 게 재밌어요. 숫자 보면 패턴 찾는 걸 잘한다고 친구들이 말해요.', '통계 수업에서 배운 걸로 학교 설문 데이터를 파이썬으로 분석해 봤어요.', '동아리에서 발표 자료 만들고 정리하는 걸 자주 맡아요.']

LLM 1회 · 관심 태그 ['Statistics', 'Data Analysis'] · 성향 태그 ['Machine Learning', 'Data Analysis'] · 강점 성향 ['탐구성', '분석성']

```
[프로필]  Statistics · Data Analysis   (성향에서 추정: Machine Learning)

[전공]    서울대학교 통계학과

          0.81 통계학과 / 0.78 첨단융합학부 / 0.64 융합학습과학전공

          기계학습과 계산금융 → Machine Learning  [서울대학교 개설]
          데이터마이닝 방법 및 실습 → Data Analysis  [서울대학교 개설]
          다변량자료분석 및 실습 → Data Analysis  [서울대학교 개설]

[직무]    LG에너지솔루션 소재개발AX (신입)
          요구 역량 2개 중 2개 커버
          ✓ Data Analysis, Machine Learning
          다음 후보: LG CNS AI (AX) (신입) — 요구 10개 중 7개 커버
```

**말할 것**
- 관심사(통계·데이터 분석)는 **사전 직행**(LLM 0회), 성향(탐구성·분석성)은 `TRAIT_TO_SKILL` 로 0.5 가중 — 화면의 "(성향에서 추정: …)" 이 그 표시. 추정은 추정이라고 밝힌다
- 팀원 `user_analysis` 모듈을 원본 수정 없이 어댑터(`interview.py`)로 연결했다 — 1인 1모듈 계약이 지켜진 사례
- LLM 호출: 이 대본은 1회(분석) + 태거 0회(사전 직행) + 설명 1회

## 예상 질문과 한 줄 답

| 질문 | 답 |
|---|---|
| 왜 어학이 없나? B2B 영업은 외국어가 핵심인데 | 어학은 역량이 아니라 지원 **요건**(OPIc IH 이상). 서울대 과목명으로 영어를 기르는 전공이 없고, Skill 로 세면 어학을 명시한 직무 16건만 불리해진다. 정보로 살리려면 soft 처럼 카드 표시만 (설명서 6-1 표) |
| 왜 서울대만? | 교육과정 데이터가 1개교. 대학 비교 축이 없어 "서울대 교육과정 기준 전공 추천" 으로 정의 |
| CNS 신입 공고가 닫혔는데? | 9/11 스냅샷. `data/raw/CNS_20260911.json` 을 지우지 않는 이유 |
| ChatGPT 에 물으면 안 되나? | 통제 어휘 밖의 말을 쓰지 않는다 · 전수 순위 · 과목명이 실제 존재 · 커버/갭 집합 연산 — 확인 3건이 매 실행 통과 |
| LLM 은 어디에 쓰나? | 판정이 아니라 **추출**(공고·과목 → 역량)과 **표현**(설명 문단). 판정은 딕셔너리 조회와 집합 연산 |
| 개수를 시키면? | "정확히 3개"·"최대 5개"·"3문장 이상" 을 시켰을 때 채우려고 지어냈다 — 프로젝트에서 4번 관측. 그래서 근거 규칙만 두고 개수는 안 시킨다 |

## 알려진 문구 이슈 (app.py 작업자에게)
- 카드의 "IT 역량이 검출된 N개" — 어휘가 IT 밖으로 넓어졌으니 "역량이 검출된 N개" 로
